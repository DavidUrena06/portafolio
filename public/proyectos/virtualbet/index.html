VirtualBet

Casino virtual y apuestas deportivas con moneda virtual. Demo sin dinero real.

Ver demo ↗ (abre en otra pestaña)Ver repositorio ↗ (abre en otra pestaña)

Problema

Un proyecto propio para construir una aplicación completa de punta a punta: base de datos, lógica de juegos en el servidor, integración con una API externa y despliegue en la nube.

Mi rol

Lo diseñé y construí completo: backend, base de datos, interfaz y despliegue.

Stack

  • Node.js
  • Express
  • Prisma
  • PostgreSQL (Supabase)
  • TheSportsDB API
  • Vercel
  • Render

Resultado

  • Aplicación desplegada y funcionando en la nube.
  • Sistema de moneda virtual y juegos: Crash, Mines, Blackjack, Keno, Plinko, CoinFlip y Dice.
  • Módulo de apuestas deportivas con datos de TheSportsDB, y funciones P2P y sociales.
  • Es una demo con moneda virtual: no usa dinero real.
